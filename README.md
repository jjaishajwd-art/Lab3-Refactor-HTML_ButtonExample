# Process Data Button

A simple interactive button project that tracks how many times an action has been performed, with a limit of 3 uses.

## Files

| File | Description |
|------|-------------|
| `index.html` | Main HTML structure |
| `style.css` | Styling and hover effects |
| `script.js` | Button logic and action tracking |

## How It Works

- Click the **Process Data** button to perform an action.
- Each click is counted and displayed below the button.
- After **3 clicks**, the button is disabled and a warning message appears.

## Features

- Click counter with live status message
- Button press animation (scale effect)
- Hover effect via CSS `:hover`
- Auto-disable after limit is reached
